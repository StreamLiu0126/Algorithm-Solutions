# P10447 最短 Hamilton 路径题解

## 题目核心

这道题的要求是：

> 从 `0` 出发，到 `n - 1` 结束，并且 `0 ~ n - 1` 中的每一个点都不重不漏地经过一次。

也就是说，这是一道 **最短 Hamilton 路径** 问题。

题目要求每个点恰好经过一次，这就意味着我们要记录：

```text
哪些点已经走过
哪些点还没有走过
```

并且每个点只有两种状态：

```text
走过 / 没走过
```

同时 `n` 比较小，满足：

```text
n <= 20
```

所以我们可以把“走过那些点”这个集合压缩成一个二进制数字。

---

## 为什么会想到状态压缩？

题目要求每个点恰好经过一次，这就说明我们在走下一个点的时候，必须知道有哪些点已经走过，这样才能判断下一个点能不能走。

也就是说，这道题需要记录的是一种“集合信息”。

而每个点只有两种状态：

```text
走过 = 1
没走过 = 0
```

所以在这题中，我们可以用同一个二进制数字 `S` 代表已经走过点的集合。

例如有 5 个点：

```text
点编号：4 3 2 1 0
状态 S：1 0 1 0 1
```

也就是：

```text
S = 10101
```

表示：

```text
0 号点已经走过
1 号点还没走过
2 号点已经走过
3 号点还没走过
4 号点已经走过
```

所以：

```text
S 表示已经走过的点的集合
```

---

## 状态压缩题目的常见特征

状态压缩题目有几种常见的特征。

### 1. 每个对象只有少数的几种状态

比如：

```text
选 / 不选
走过 / 没走过
开 / 关
放 / 不放
用过 / 没用过
```

这道题里面，每个点只有：

```text
走过 / 没走过
```

所以可以用二进制位来表示。

---

### 2. 题目需要记录“集合”

比如：

```text
已经访问了哪些点？
已经选择了哪些物品？
哪些灯现在是开的？
当前这一行哪些格子放了东西？
```

这道题要记录的就是：

```text
已经走过哪些点？
```

这正好是一个集合。

---

### 3. n 比较小

因为状态数量是指数级的。

如果有 `n` 个点，每个点都有两种状态，那么总状态数是：

```text
2^n
```

这道题中：

```text
n <= 20
```

所以：

```text
2^20 = 1048576
```

大约是一百万个状态，可以接受。

---

### 4. 转移和“集合变化”有关

比如：

```text
从已经走过的集合 S，再走到一个没走过的点 j
从已经选了的集合 S，再加入一个物品 i
```

这道题中的转移就是：

```text
当前已经走过集合 S
现在停在点 i
尝试走到一个还没有走过的点 j
```

走到 `j` 之后，新的集合就是：

```cpp
S | (1 << j)
```

也就是把第 `j` 位变成 `1`。

---

## 状态设计

这道题不能只用：

```cpp
dp[S]
```

因为只知道“已经走过哪些点”是不够的。

比如同样走过了 `{0, 1, 2}`，但是：

```text
当前停在 1
```

和：

```text
当前停在 2
```

接下来走到点 `3` 的代价是不一样的。

所以我们还要知道：

```text
当前停在哪个点
```

因此状态设计为：

```cpp
dp[S][i]
```

含义是：

```text
已经走过集合 S 中的所有点，并且当前停在 i 号点时的最短路径长度。
```

其中：

```text
S：已经走过哪些点
i：当前停在哪个点
```

---

## 初始化

初始化的操作是：

```cpp
dp[1][0] = 0;
```

意思是：

```text
刚开始只走过 0 号节点，当前也在 0 号节点，路径长度为 0。
```

为什么是 `1`？

因为一开始只经过了 `0` 号点。

第 `0` 位为 `1`，其余位为 `0`：

```text
000...0001
```

这个二进制数对应的十进制就是：

```text
1
```

所以初始状态是：

```cpp
S = 1
```

因此：

```cpp
dp[1][0] = 0;
```

---

## 状态转移

假设当前状态是：

```cpp
dp[S][i]
```

表示：

```text
已经走过集合 S 中的点，现在停在 i 号点。
```

接下来我们枚举一个点 `j`，如果 `j` 还没有走过，就可以从 `i` 走到 `j`。

判断 `j` 有没有走过：

```cpp
if (S & (1 << j)) continue;
```

如果这一位已经是 `1`，说明 `j` 已经走过，不能再走。

如果 `j` 还没有走过，那么新的状态是：

```cpp
int nxt = S | (1 << j);
```

表示把 `j` 加入已经走过的集合。

于是状态转移为：

```cpp
dp[nxt][j] = min(dp[nxt][j], dp[S][i] + a[i][j]);
```

意思是：

```text
从当前点 i 走到点 j，
路径长度增加 a[i][j]，
当前停留点变成 j。
```

---

## 答案

题目要求：

```text
从 0 出发，最后到 n - 1
并且所有点都恰好经过一次
```

所有点都经过时，状态是：

```text
111...111
```

对应代码：

```cpp
int full = (1 << n) - 1;
```

因为终点必须是 `n - 1`，所以答案是：

```cpp
dp[full][n - 1]
```

不能写成：

```cpp
min(dp[full][i])
```

因为那表示最后停在哪个点都可以。

但是题目明确要求：

```text
终点必须是 n - 1
```

---

## 时间复杂度

这题的三层循环是：

```cpp
for (int S = 0; S < (1 << n); S++) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            ...
        }
    }
}
```

所以时间复杂度是：

```text
O(2^n * n * n)
```

也就是：

```text
O(n^2 * 2^n)
```

因为 `n <= 20`，所以理论上最多大约：

```text
20 * 20 * 2^20
```

虽然看起来比较大，但是转移过程中会进行剪枝，例如：

```cpp
if (!(S & (1 << i))) continue;
if (dp[S][i] == INF) continue;
if (S & (1 << j)) continue;
```

所以实际转移会少很多。

---

## 空间复杂度

DP 数组是：

```cpp
dp[1 << n][n]
```

所以空间复杂度是：

```text
O(n * 2^n)
```

当 `n = 20` 时，大约有：

```text
20 * 2^20
```

个状态。

如果用 `int` 存，大约是几十 MB，可以接受。

---

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 20;
const int INF = 1e9;

int n;
int a[N][N];
int dp[1 << 20][N];

void solve() {
    cin >> n;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> a[i][j];
        }
    }

    int total = 1 << n;

    for (int S = 0; S < total; S++) {
        for (int i = 0; i < n; i++) {
            dp[S][i] = INF;
        }
    }

    // 初始状态：只走过 0 号点，当前停在 0 号点，路径长度为 0
    dp[1][0] = 0;

    for (int S = 0; S < total; S++) {
        for (int i = 0; i < n; i++) {
            // i 必须在 S 中，否则不可能停在 i
            if (!(S & (1 << i))) continue;

            // 当前状态不可达
            if (dp[S][i] == INF) continue;

            // 枚举下一个要走的点 j
            for (int j = 0; j < n; j++) {
                // 如果 j 已经走过，就不能再走
                if (S & (1 << j)) continue;

                int nxt = S | (1 << j);

                dp[nxt][j] = min(dp[nxt][j], dp[S][i] + a[i][j]);
            }
        }
    }

    int full = total - 1;

    // 所有点都走过，并且最后必须停在 n - 1
    cout << dp[full][n - 1] << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    solve();

    return 0;
}
```

---

## 总结

这道题的思考过程是：

```text
1. 题目要求每个点恰好经过一次，所以要记录哪些点已经走过。
2. 每个点只有走过 / 没走过两种状态。
3. n <= 20，状态数 2^n 可以接受。
4. 所以用二进制数字 S 表示已经走过的点的集合。
5. 因为下一步的距离和当前停在哪个点有关，所以状态设计为 dp[S][i]。
6. dp[S][i] 表示已经走过集合 S，当前停在 i 的最短路径长度。
7. 从 i 走到一个没走过的点 j，转移到 dp[S | (1 << j)][j]。
8. 初始状态是 dp[1][0] = 0。
9. 最终答案是 dp[(1 << n) - 1][n - 1]。
```
