# P2622 关灯问题 II 题解

## 思路整理

首先每盏灯只有两种状态：开或不开，并且 n 很小，所以总状态只有 $2^{10} = 1024$ 种，非常小。

所以我们可以把所有灯的状态压缩成一个数字。

一开始的状态是：

```text
111……1
```

最终要变成：

```text
000……0
```

题目问的是最少要按几次。

---

## 预处理按钮

题目还给了一个重要的信息是一个按钮会对所有的灯都进行一种操作，所以我们可以先预处理两个二进制数 `off` 和 `on`，分别代表这个按钮会关掉那些灯，会打开那些灯。

例如，按钮为：

```text
1 0 1
```

时：

```text
off = 101
on = 000
```

---

## 状态转移

假设当前状态是 `S`，按下第 `i` 个按钮后：

```cpp
int nxt = (S & ~off[i]) | on[i];
```

这句话分两步理解：

第一步：

```cpp
S & ~off[i]
```

把 `off[i]` 中为 `1` 的那些灯关掉。

第二步：

```cpp
| on[i]
```

把 `on[i]` 中为 `1` 的那些灯打开。

所以完整转移就是：

```cpp
nxt = (S & ~off[i]) | on[i];
```

---

## 为什么想到 BFS？

这道题为什么又想到 BFS 呢？

如果是普通的状态压缩 DP，常见的情况是状态越来越大，这样就可以按照状态从小到大递推。

但是这题按下按钮可能开灯也可能关灯，所以状态可能这样变化：

```text
111 -> 101 -> 001 -> 011 -> 000
```

因此这道题没有固定的递推顺序。

但是我们可以把每一个状态看成一个点，每次按下一个按钮，就是从一个状态走到另一个状态，而且每一次的权值是 1，这样就可以用 BFS 来解决图上的最短路问题。

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long

/*
1.判断第 i 位是否为 1
if (S & (1 << i))

2.把第 i 位变成 1
S | (1 << i)

3.把第 i 位变成 0
S & ~(1 << i)

4.取反某一位
S ^ (1 << i)

5.枚举所有状态
for (int S = 0; S < (1 << n); S++) {
	
}

6.枚举状态 S 中所有为 1 的位置
for (int i = 0; i < n; i++) {
	if (S & (1 << i)) {
	
	}
}

*/

/*
从 n 个东西里选择若干个
每个东西选或不选
求最大值 / 最小值 / 方案数
*/

const int INF = 1e9;
const int N = 15;
const int M = 105;
const int MAX = 2050;
int n, m;
int dist[MAX];
int off[M];
int on[M];

void solve() {
	cin >> n >> m;
	for (int i = 0; i < m; i++) {
		for (int j = 0; j < n; j++) {
			int x;
			cin >> x;
			if (x == 1) {
				//如果是 1 的话会关掉灯
				off[i] |= (1 << j);
			} else if (x == -1) {
				//如果是 -1 的话会打开灯
				on[i] |= (1 << j);
			}
		}
	}

	for (int i = 0; i <= (1 << n); i++) {
		dist[i] = -1;
	}


	dist[(1 << n) - 1] = 0;
	queue<int> q;
	q.push((1 << n) - 1);
	while (!q.empty()) {
		int S = q.front();
		q.pop();

		if (S == 0) {
			break;
		}

		for (int i = 0; i < m; i++) {
			int nxt = (S & ~(off[i])) | on[i];
			if (dist[nxt] == -1) {
				dist[nxt] = dist[S] + 1;
				q.push(nxt);
			}
		}
	}

	cout << dist[0] << endl;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(0);

	int _ = 1;
	// cin >> _;
	while (_--) {
		solve();
	}
}
```
