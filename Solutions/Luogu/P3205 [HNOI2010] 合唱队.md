# P3205 [HNOI2010] 合唱队题解

## 题目链接

[洛谷 P3205 [HNOI2010] 合唱队](https://www.luogu.com.cn/problem/P3205)

## 思路分析

这题的题干给的是最终队形，然后问了有多少种初始队形，经过规则插入以后可以得到这个最终队形。

因为初始队形不知道，我们也不能一个个去尝试每种初始队形，这样百分百超时。但是我们可以根据最终队形反推。

因为每一次插入只能插入到队首或者是队尾，所以我们可以根据此时的队形确定上一次是什么队形。

举个例子：

如果要得到最终队形：

```text
1 2 3 4
```

那么上一次的队形一定就是：

```text
2 3 4
```

或者是：

```text
1 2 3
```

有且只有这两种情况。

所以我们就可以分为两种大情况：

第一种就是上一次插入的是左边：对应的就是 `2 3 4` 插入 `1`。

第二种就是上一次插入的是右边：对应的就是 `1 2 3` 插入 `4`。

但是每种大情况又分为两种小情况。

在第一种大情况中我们插入 `1` 的时候，我们比较的是哪个位置的数字？是第一个位置的 `2` 还是最后一个位置的 `4`？

第二种大情况也是同理。

所以我们只要分为四种情况来讨论即可。

## 区间 DP 特征

这道题有哪些区间 DP 的特征？

首先每一次操作只会影响两边的排列，而中间的排列还是可以使用，而且中间的一定是连续区间。

最重要的是最后插入的人只有两种可能，就跟我们上边所说的两种大情况一样，这就满足了大区间可以有小区间扩展的到的特性。

而且我们可以观察到这道题的数据范围很小。

## 状态设计

设：

```cpp
dp[l][r][0]
```

表示已经形成了区间 `[l, r]`，并且最后一次插入的是左端点 `h[l]` 的方案数。

设：

```cpp
dp[l][r][1]
```

表示已经形成了区间 `[l, r]`，并且最后一次插入的是右端点 `h[r]` 的方案数。

## 四种情况

对于当前区间 `[l, r]`，最后插入的人只有两种可能：

- 最后插入的是左端点 `h[l]`
- 最后插入的是右端点 `h[r]`

但是每种大情况又要看上一次插入的人是谁，所以一共是四种情况。

### 情况一：最后插入的是左端点，之前最后插入的是 `h[l + 1]`

如果 `h[l] < h[l + 1]`，说明 `h[l]` 可以插到左边。

```cpp
if (h[l] < h[l + 1]) {
    dp[l][r][0] += dp[l + 1][r][0];
}
```

### 情况二：最后插入的是左端点，之前最后插入的是 `h[r]`

如果 `h[l] < h[r]`，说明 `h[l]` 可以插到左边。

```cpp
if (h[l] < h[r]) {
    dp[l][r][0] += dp[l + 1][r][1];
}
```

### 情况三：最后插入的是右端点，之前最后插入的是 `h[l]`

如果 `h[r] > h[l]`，说明 `h[r]` 可以插到右边。

```cpp
if (h[r] > h[l]) {
    dp[l][r][1] += dp[l][r - 1][0];
}
```

### 情况四：最后插入的是右端点，之前最后插入的是 `h[r - 1]`

如果 `h[r] > h[r - 1]`，说明 `h[r]` 可以插到右边。

```cpp
if (h[r] > h[r - 1]) {
    dp[l][r][1] += dp[l][r - 1][1];
}
```

## 转移总结

```cpp
if (h[l] < h[l + 1]) dp[l][r][0] += dp[l + 1][r][0];
if (h[l] < h[r])     dp[l][r][0] += dp[l + 1][r][1];

if (h[r] > h[l])     dp[l][r][1] += dp[l][r - 1][0];
if (h[r] > h[r - 1]) dp[l][r][1] += dp[l][r - 1][1];
```

记得每次转移都要对 `19650827` 取模。

## 初始化

长度为 `1` 的区间只有一个人，所以：

```cpp
dp[i][i][0] = 1;
dp[i][i][1] = 0;
```

这里不需要把两个状态都初始化为 `1`，否则会重复计算。

## 答案

最后答案就是整个区间 `[1, n]` 的方案数：

```cpp
ans = (dp[1][n][0] + dp[1][n][1]) % MOD;
```

## 总结

这题可以这样理解：

因为题目给的是最终队形，所以我们可以反过来想。

每一次反推的时候，最后插入的人只可能是当前区间的左端点或者右端点，所以这题可以用区间 DP 来处理。

它不是普通的合并型区间 DP，而是由小区间向大区间扩展的区间 DP。



```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long 

int n;
const int N = 1005;
const int INF = 1e18;
int a[N];
int dp[N][N][2];
const int MOD = 19650827;

void solve() {
	cin >> n;
	for (int i = 1; i <= n; i++) {
		cin >> a[i];
	}

	for (int i = 1; i <=n ;i++) {
		dp[i][i][1] = 1;
	}

	for (int len = 2; len <= n; len++) {
		for (int l = 1; l + len - 1 <= n; l++) {
			int r = l + len - 1;

			if (a[l] < a[l + 1]) {
				dp[l][r][0] += dp[l + 1][r][0];
				dp[l][r][0] %= MOD;
			}

			if (a[l] < a[r]) {
				dp[l][r][0] += dp[l + 1][r][1];
				dp[l][r][0] %= MOD;
			}

			if (a[r] > a[l]) {
				dp[l][r][1] += dp[l][r - 1][0];
				dp[l][r][1] %= MOD;
			} 

			if (a[r] > a[r - 1]) {
				dp[l][r][1] += dp[l][r - 1][1];
				dp[l][r][1] %= MOD;
			}
		}
	}

	int ans = (dp[1][n][0] + dp[1][n][1]) % MOD;
	cout << ans;


}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(0);

	int _ = 1;
	// cin >> _;
	while (_--) {
		solve();
	}

}
```
